# 00. 基礎

本章は以降の章全体で断りなく用いる記法, 公理, 定理を述べる.

## 記法規約

- $\mathbb{Z}$: 整数全体の集合 $\{\dots, -2, -1, 0, 1, 2, \dots\}$.
- $\mathbb{Z}_{>0}$: 正の整数全体の集合 $\{1, 2, 3, \dots\}$.
- $\mathbb{N}$: 自然数（非負整数）全体の集合 $\{0, 1, 2, \dots\}$. ($0$ を含む)
- $d\mathbb{Z}$: $d \in \mathbb{Z}$ に対して, $d$ の倍数全体の集合
  $\{\dots, -2d, -d, 0, d, 2d, \dots\}$.

## 公理 1 (整列性)

$\mathbb{N}$ の空でない任意の部分集合は最小元を持つ.
